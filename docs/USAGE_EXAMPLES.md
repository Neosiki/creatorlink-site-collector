# 사용 사례와 FAQ

명령과 옵션은 `docs/MANUAL.md`, AI 도구 설치는 `docs/INSTALL_AI.md`를 보십시오. 이 문서의 숫자와 메뉴 이름은 설명용 예시입니다.

## 1. 사례

### 사례 A. 작가 포트폴리오로 온라인 도록 만들기

이 도구가 처음 쓰인 경우입니다. 작가의 허락을 받은 뒤 메뉴를 하나씩 끝내며 진행했습니다.

1. `discover`로 메뉴 20개와 소유자 id를 확인합니다.
2. 메뉴 하나를 `collect --menu <path>`로 받고 `verify`를 돌립니다.
3. 보고를 받고 다음 메뉴로 넘어갑니다. 허락이 있으면 `--all`로 이어서 진행하되, 메뉴마다 보고를 남깁니다.
4. 끝나면 `verify`와 `master`를 실행합니다. `master_파일명대응표.csv`에 전체 이미지의 파일명, 크기, 원본 주소, 제목, 캡션이 모입니다.
5. 도록을 만들 때 대응표를 기준으로 순서를 정하고, 캡션의 가격이나 연락처는 공개 범위를 작가와 확인한 뒤 옮깁니다.
6. 인쇄용이 필요하면 해상도를 `가로px` 열에서 확인해 작은 메뉴만 작가에게 원본을 따로 요청합니다.

### 사례 B. 매장·브랜드 사이트 백업과 이전

사이트를 다른 빌더로 옮기기 전에 이미지와 설명 글을 모아 둘 때 씁니다. `--all`로 전체를 받고 `--lang en`을 주면 영문 폴더 이름이라 다른 도구에서 다루기 편합니다. 설명 글은 메뉴 폴더의 `작품설명.txt`(영문 모드는 `description.txt`)에 있습니다.

### 사례 C. 일부 메뉴만 다시 받기

사이트에 작품이 추가됐다면 해당 메뉴만 다시 실행합니다. 이전 결과와 다른 파일은 지우지 않고 `_이전파일`로 옮겨 두니, 확인한 뒤 직접 지우십시오.

```bash
python3 scripts/collect.py collect --base https://○○.creatorlink.net --out ./output --menu 해인사
python3 scripts/collect.py verify --out ./output
```

### 사례 D. 내려받은 결과를 AI로 정리하기

수집이 끝난 `파일명대응표.csv`는 AI에게 붙여 넣기 좋은 자료입니다. 예를 들어 "제목이 비어 있는 행을 찾아 목록으로 만들어 줘", "캡션에서 가격이 들어간 행만 뽑아 줘", "도록 장 구성을 메뉴 기준으로 제안해 줘" 같은 요청입니다. 파일을 올리기 전에 캡션에 개인정보가 없는지 확인하십시오.

## 4. FAQ와 문제 해결

**403 또는 연결 오류가 납니다.**
사이트 도메인, `storage.googleapis.com`, `lh3.googleusercontent.com` 세 곳 중 하나가 막힌 것입니다. 회사나 AI 서비스의 네트워크 허용 목록을 확인하십시오. 막힌 채로 나온 결과는 완료로 보지 마십시오.

**`--menu`에 메뉴 이름을 넣었더니 "홈 메뉴에 없는 경로"라고 나옵니다.**
`--menu`에는 이름이 아니라 `discover` 출력의 `path` 값을 넣습니다. 공백이 있는 이름은 `path`에서 하이픈으로 바뀌어 있습니다(예: `해브-갤러리`).

**중간에 `PARTIAL`이라고 멈췄습니다.**
오류가 아니라 한 번의 실행 시간(`--budget`, 기본 140초)을 다 쓴 것입니다. 같은 명령을 다시 실행하면 이어서 받습니다. 종료 코드는 2입니다.

**`수집미완료.txt`가 생겼습니다.**
목록 요청이 실패한 메뉴입니다. 다시 실행해서 `수집완료.txt`로 바뀌는지 확인하십시오. 계속 실패하면 `status.json`의 `api_failed`를 보고, 사이트 구조가 바뀌었는지 `docs/SITE_STRUCTURE.md`와 대조하십시오.

**저장된 수가 목록 API 작품 수와 다릅니다.**
정상일 수 있습니다. 같은 사진이 여러 목록에 겹치거나(고유 이미지 수는 `api_unique`), 내용이 같은 파일이 합쳐졌거나(`covered_by_content_duplicate`), 소개 섹션과 상세 페이지의 이미지가 더해졌기 때문입니다. `verify`의 `UNCOVERED`가 비어 있으면 빠진 것은 없습니다.

**`source_file_missing`이 있습니다.**
목록에는 있지만 사이트 저장소에서 파일이 삭제된 경우입니다. 이 도구로는 받을 수 없으니 작가에게 원본을 요청하십시오.

**해상도가 낮습니다.**
사이트가 가진 최대 크기까지 받습니다. 메뉴에 따라 800~1200px뿐입니다. 인쇄용은 작가에게 원본을 받아야 합니다.

**영상 파일은 어디 있나요?**
받지 않습니다. `영상/영상목록.csv`에 YouTube 등의 주소만 기록합니다. 일부는 삭제·비공개일 수 있습니다.

**게시판 메뉴가 비어 있습니다.**
글 목록을 관리자만 볼 수 있게 설정된 메뉴입니다. 공개된 글이 없어 수집할 것이 없습니다.

**이미 받은 폴더를 지우고 싶습니다.**
이 도구는 파일을 지우지 않고 `_이전파일`로 옮깁니다. 필요 없는 폴더는 직접 지우십시오. `.cache` 폴더는 이어받기용이라 수집이 모두 끝난 뒤에는 지워도 됩니다.

**Windows에서 한글이 깨집니다.**
PowerShell에서 `$env:PYTHONUTF8=1`을 실행한 뒤 다시 시도하거나 WSL을 쓰십시오. 이 부분은 직접 검증하지 못했습니다.

**다른 사이트 빌더(Wix, Cafe24 등)에도 쓸 수 있나요?**
쓸 수 없습니다. Creatorlink(애드블록) 사이트의 구조에 맞춘 도구입니다.

**수집해도 되는 사이트인가요?**
사이트 운영자와 작가가 허락한 용도에만 쓰십시오. 저작권은 작가에게 있고, 이 저장소에는 이미지를 올리지 않습니다.
